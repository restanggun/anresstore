# Pengelolaan repository

Direkomendasikan satu repository GitHub private. Akun, repository remote, lisensi,
CODEOWNERS, dan proteksi branch belum diatur. Jangan memilih lisensi otomatis.
Branch utama `main`; pekerjaan menggunakan `feat/*`, `fix/*`, `docs/*`.
Setelah tersedia, aktifkan PR review, required CI, dan proteksi main di GitHub.
