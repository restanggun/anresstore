# Profil perusahaan Anres Store

Anres Store adalah toko online untuk kebutuhan digital sehari-hari. Pelanggan dapat menjelajahi pilihan layanan, melihat harga dan ketentuan, lalu memesan dan memantau statusnya melalui invoice.

## Pelanggan yang kami layani

Anres Store melayani pemain game, pengguna media sosial, serta pelanggan yang mencari pulsa, paket data, aplikasi premium, atau bantuan untuk dokumen dan presentasi.

## Pilihan layanan

| Kategori | Contoh dan informasi yang perlu diperiksa |
| --- | --- |
| Top up game | Pilih judul dan nominal top up, lalu periksa ID pemain dan zona bila diminta. |
| Joki tugas | Pilih bantuan untuk dokumen atau presentasi sesuai lingkup, tenggat, dan opsi revisi pada paket. |
| Booster media sosial | Pilih layanan sesuai platform, jenis paket, dan ketentuan yang tercantum. |
| Aplikasi premium | Bandingkan jenis akses, masa aktif, dan ketentuan paket, termasuk garansi jika dicantumkan. |
| PPOB | Lihat pilihan pulsa, paket data, token listrik, dan isi saldo e-wallet. |

## Belanja dan bantuan

Gunakan Katalog untuk mencari produk dan melihat ketentuannya. Ikuti petunjuk pembayaran saat checkout. Setelah itu, gunakan Invoice untuk memantau pembayaran dan proses pesanan.

Pusat Bantuan menyediakan jawaban cepat, asisten AI, dan tiket untuk berbicara dengan tim CS. Masuk ke akun untuk membuka tiket dan membaca balasan.
