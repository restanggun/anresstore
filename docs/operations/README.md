# Operations

Start with the [release checklist](release-checklist.md), then follow the [VPS deployment runbook](vps-deployment.md). The [VPS readiness audit](vps-readiness-audit.md) lists the environment-specific checks that still need evidence before launch.

For day-to-day work, see the guides for [catalog management](catalog-management.md), [live transactions](live-transactions.md), [refund requests](refund-requests.md), [support notifications](support-notifications.md), and [transaction operations](transaction-operations.md). The [admin dashboard guide](admin-dashboard.md) covers operator access and MFA.

Keep secret values out of repository files, logs, and support tickets. When a payment or supplier result is ambiguous, reconcile its status before retrying an operation.
