# Kesiapan VPS

Repository memakai pembayaran produksi, promo dari data server, dan status pemenuhan terverifikasi. Terapkan migrasi hingga 20261118151000_profile_permissions.sql sebelum memasang API ini. Petunjuk deployment ada di [runbook VPS](vps-deployment.md).

Kesiapan deployment memerlukan konfigurasi secret produksi, penerapan migrasi remote, build image Linux, DNS/TLS, backup, monitoring, serta verifikasi transaksi pada VPS. Dokumen ini tidak menyatakan langkah tersebut sudah dilakukan. Catat hasil validasi release dan transaksi provider secara terpisah.
