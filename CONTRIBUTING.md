# Kontribusi

Gunakan Node >=22.18 dan npm >=10. Baca README dan AGENTS.md terlebih dahulu.
Kerjakan perubahan pada feat/*, fix/* atau docs/*. Gunakan commit deskriptif,
misalnya `feat(catalog): add product availability`.
Jalankan typecheck, test dan build. Migrasi SQL serta tipe database harus sejalan.
Jangan commit secret atau data produksi. Jelaskan perilaku, validasi, dan dampak
migrasi pada PR. Lisensi kontribusi belum diputuskan pemilik.
